# 学完后的目标（毕业标准）

一句话：你能把**自己训练的小 GPT**从 PyTorch 走到可对拍的多后端推理，并且能按瓶颈选工具，而不是把 ONNX / TensorRT / GGML / vLLM 当成同一把锤子。

这是「大模型部署入门毕业」，不是「生产级 LLM 平台工程师毕业」。

---

## 你必须能独立做到的事

1. **讲清并改模型**  
   不看资料画出 Block：LN、QKV、因果掩码、缩放、残差、FFN。能改 `n_layer / n_embd` 并知道显存大致怎么变。

2. **训练并拥有权重**  
   从文本 → tokenizer → loss 右移 → `checkpoint.pt` → greedy 采样。权重是你的，后面所有后端都吃它。

3. **解释并实现「生成为什么慢」**  
   区分 prefill / decode。实现 KV cache。naive 与 cache 的 16 个 greedy token 完全一致，且能测出 TPOT 下降。

4. **用数字说话**  
   会测 TTFT、TPOT、吞吐、显存。换后端先对拍 token，再比速度。没有表不许说「加速了」。

5. **按瓶颈选运行时（口试必过）**

   | 真实需求 | 你选 |
   |----------|------|
   | 单请求 decode 在重算历史 | KV cache，不是先上 TRT |
   | 换机器 / 给编译器吃图 | ONNX + ORT |
   | GPU 上榨单图前向 | TensorRT |
   | CPU / 端侧 / 量化 / C++ | GGML |
   | 很多并发请求、KV 显存碎片 | mini-vLLM 这类服务，不是再压 GEMM |

6. **同一套权重走通至少三条路径**（没 GPU 则 TRT 允许降级）  
   PyTorch+KV、ONNX Runtime、C++/GGML；有卡再加上 TensorRT。另有一个教学级连续批处理引擎（mini-vLLM），吞吐表是自己跑出来的。

## 毕业口试（闭卷，全答上才算学完）

1. 第 t 步 decode 为什么不必重算 1…t-1 的 K/V？位置编码取几？
2. ONNX 为什么不保证比 PyTorch 快？
3. TensorRT 和 vLLM 各优化哪一层？单请求 batch=1 时 vLLM 一定会更快吗？
4. GGML 量化改变的是什么（内存/带宽/精度），它是不是写 vLLM 的前置？
5. 给你「线上 100 QPS、平均输出 200 token」和「笔记本离线跑自己的模型」，分别选哪条支线，为什么？

## 两级毕业

- **主干毕业（L10）**：会模型、会训练、会 KV cache、会测量。已经比「会调 API」强一个数量级。  
- **全计划毕业（L20）**：同一套权重，能讲、能对拍、能选对后端。这才是本仓库写上的终点。

## 学完在真实世界能干什么

这门课给你的是**推理栈的读写能力**，不是立刻去管 70B 集群的资格。

**马上能做的事**

- 把「模型很慢」拆成：没 cache、batch 不对、在 CPU 上、导出没对拍、不该用服务框架却硬上。
- 给自己的小模型做本地 Demo：Python 生成、ONNX 跨环境、C++ 可执行文件。
- 读 vLLM / llama.cpp / TensorRT-LLM 的文档和 issue，知道他们在说哪一层。
- 面试「模型部署 / 推理优化 / 边缘侧」初级岗位时，用本仓库当作品集（有对拍数字，不是教程截图）。
- 进组后能给训练同学当翻译：他们要吞吐，你知道该动 cache、调度还是编译器。

**L10 主干结束后就能做**

- 自己的玩具模型能训、能生成、能讲为什么 decode 慢。适合先交差、再决定要不要开支线。

**L20 全计划结束后更能做**

- 在几个后端之间做取舍实验，并写出「这个模型在我这台机器上」的延迟表。
- 继续往下：读官方 vLLM 源码、往 llama.cpp 加自定义结构、接 TensorRT-LLM、做量化/投机解码加课。

**仍然不能直接做的**

- 独立负责公司 7B+ 在线服务的 SLA、多机多卡、KV 池生产实现。
- 顶替 CUDA 内核工程师或完整 ML 平台组。

## 找工作 / 读研 定位

投入量约等于一门实践课，不是一段实习，也不是一篇论文。

**找工作**

- 对得上：校招/实习作品集里的「推理栈」部分；端侧、部署、ML 平台实习的入门门票。
- 对不上：大厂「推理优化工程师」正式岗的主技能（还缺真实大模型、CUDA/TRT-LLM 生产经验、实习）。
- 纯 LLM 算法岗：这是加分项（你懂部署），主信号仍是实习、微调/评测、业务结果。
- 转行社招：单独这仓库不够当 1–3 年经验；要再叠一段真实模型上的项目或实习。

**研究生**

- 对得上：本科毕设 / 硕士入学前补课 / MLSys、高效推理方向的预研脚手架。
- 对不上：硕士论文或顶会投稿本身。论文还要：问题、相关工作、公开模型与 benchmark、对比实验。
- NLP/对齐/Agent 方向：帮你跑通系统，研究贡献仍在方法与实验，不在「会写 mini-vLLM」。
